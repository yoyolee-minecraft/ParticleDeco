# Particle Deco 材料對照表

適用版本：Particle Deco 1.0.8 以上，Minecraft 26.2。

材料名稱使用遊戲內繁體中文（台灣）的正式名稱。把材料拿在手上，右鍵等待填入（黃色框線）的方塊，就會開始播放對應的粒子。這份表是伺服器預設的 `config/particledeco/materials.json`，伺服器管理員可以自行修改。

## 補充說明

- 物品 ID 省略了 `minecraft:` 前綴；`#` 開頭的是物品標籤，代表一整類物品。
- 帶參數的粒子：紅石粉的顏色可以在設定介面用染料更改；混凝土粉末的塵粒顏色取自放入的那一種；藥水的漩渦顏色取自藥水內容；伏聆振測器使用振測器本身的配色。
- 營火與乾草捆使用原版營火的隨機節奏，設定介面裡的形狀、大小、數量與間隔不會套用。
- 刻意不收錄的粒子：只在水中存在的粒子（`bubble`、`bubble_column_up`、`current_down`），離開水會立刻消失；會遮住畫面或干擾玩家的粒子（`elder_guardian`、`sonic_boom`、`flash`、`explosion_emitter`）。
