Particle Deco 1.0.7

- 修正黃色框線的計時起點：60 秒改成從「收起粒子核心或刷子」那一刻開始算。之前是從綁定那一刻開始算，手上一直拿著核心的話，收起來時往往早就超過 60 秒，黃色框線會馬上消失。
- 現在的行為：手持核心或刷子時顯示所有框線；收起工具後青色框線立刻消失，黃色框線保留 60 秒再消失。重新拿起工具會重新計時。
- 計時是每位玩家各自計算，沒拿過工具的玩家不會看到黃色框線。
- 設定 `outline.waitingShowSeconds` 不變：`0` 代表收起工具就一起消失，`-1` 代表黃色框線永遠顯示。

需求：Minecraft 26.2 以上、Fabric Loader 0.18.4 以上、Fabric API、Java 25。
