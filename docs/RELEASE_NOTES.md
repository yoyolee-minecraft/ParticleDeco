Particle Deco 1.0.8

- 修正花盆的問題：對綁定過的花盆右鍵把花拿出來，花盆會失去粒子核心，播放中的花盆還會連粒子材料一起掉出來。原因是原版的「插著花的花盆」和「空花盆」是兩種不同的方塊，模組把種類改變當成方塊被換掉。
- 現在只有方塊被破壞才會解除綁定：玩家挖掉，或該位置變成空氣、液體、氣泡柱、火（爆炸、活塞推走、燒毀等）。
- 同類問題一併修正，以下情況現在都會保留發射點與粒子：
  - 花盆放入或拿出植物
  - 鍋釜裝水、熔岩、粉雪或舀空
  - 斧頭剝皮原木與木頭、銅方塊氧化、上蠟、刮除
  - 鐵砧使用後變成微損的鐵砧、耗損的鐵砧
  - 珊瑚方塊離開水變成死亡的珊瑚方塊
  - 草地被鏟成土徑、被鋤成耕地、耕地被踩回泥土
  - 用剪刀把南瓜變成雕刻過的南瓜、濕海綿與海綿互換、插上蠟燭的蛋糕拿掉蠟燭
- 效能測試改用中位數並延長暖機，避免 CI 機器忙碌時誤判；門檻維持 1 ms。

需求：Minecraft 26.2 以上、Fabric Loader 0.18.4 以上、Fabric API、Java 25。
